以下の手順でセッションの引き継ぎドキュメントを作成してください。

## 手順

1. **現在の状況を把握する**
   - git status、git diff、git log を確認し、現在のブランチとコミット状況を把握する
   - TodoWrite の残タスクがあれば確認する
   - 作業中のファイル変更を確認する

2. **HANDOVER.md をプロジェクトルートに生成する**

以下のフォーマットに従って `HANDOVER.md` を作成してください：

```markdown
# セッション引き継ぎドキュメント

## 作業ブランチ
- ブランチ名: （現在のブランチ名）

## 完了した作業
- （このセッションで完了したタスクをリストアップ）

## 未完了の作業
- （まだ完了していないタスクをリストアップ）
- （ある場合は、なぜ未完了なのか理由も記載）

## 現在の状態
- ビルド状態: （成功/失敗/未確認）
- テスト状態: （成功/失敗/未確認）
- 未コミットの変更: （あり/なし）

## 既知の問題・ブロッカー
- （発見したバグや問題点を記載）
- （解決できなかった課題を記載）

## 重要なコンテキスト・決定事項
- （設計上の判断や、次のセッションで知っておくべき背景情報）
- （依存関係や注意点）

## 次のステップ
- （次のセッションで最初に取り組むべきこと）
- （推奨する作業順序）

## 関連ファイル
- （主に変更・参照したファイルのパス一覧）
```

3. **生成後の確認**
   - HANDOVER.md の内容が正確かレビューする
   - ファイルをコミットはしない（次のセッション開始時に確認してもらうため）
