# 認証機能セットアップガイド

## 概要

TierHubではGoogle認証とApple認証をサポートしています。このガイドでは、認証機能を有効化するための手順を説明します。

## 前提条件

- Firebase プロジェクトが作成済みであること
- `.env` ファイルにFirebase設定が記載されていること

## 📱 Google認証の設定

### 1. Firebase Consoleでの設定

1. [Firebase Console](https://console.firebase.google.com/) にアクセス
2. プロジェクト（tierhub-c1b9f）を選択
3. 左メニューから「Authentication」→「Sign-in method」を選択
4. 「Google」を有効化
   - 「Enable」をON
   - プロジェクトのサポートメールを選択
   - 「保存」をクリック

### 2. Web Client IDの取得

Firebase Consoleの「Authentication」→「Sign-in method」→「Google」の設定画面で、**Web Client ID**が表示されます。

または、Google Cloud Consoleから取得：

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. プロジェクトを選択
3. 左メニュー「APIs & Services」→「Credentials」
4. 「Web client (auto created by Google Service)」という名前のOAuth 2.0クライアントIDを探す
5. Client IDをコピー

### 3. iOS用Client ID（オプション）

iOS用のネイティブGoogle Sign-Inを使用する場合：

1. Google Cloud Console → Credentials
2. 「CREATE CREDENTIALS」→「OAuth client ID」
3. Application type: **iOS**
4. Bundle ID: `com.yourcompany.tierhub`（app.jsonのbundleIdentifierと一致させる）
5. 作成後、Client IDをコピー

### 4. Android用Client ID（オプション）

Android用のネイティブGoogle Sign-Inを使用する場合：

1. Google Cloud Console → Credentials
2. 「CREATE CREDENTIALS」→「OAuth client ID」
3. Application type: **Android**
4. Package name: `com.yourcompany.tierhub`（app.jsonのpackageと一致させる）
5. SHA-1証明書フィンガープリントを追加：
   ```bash
   # 開発用SHA-1の取得
   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
   ```
6. 作成後、Client IDをコピー

### 5. .envファイルへの設定

取得したClient IDを `.env` ファイルに追加：

```env
# Google OAuth
EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=your-web-client-id.apps.googleusercontent.com
EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID=your-ios-client-id.apps.googleusercontent.com
EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID=your-android-client-id.apps.googleusercontent.com
```

**重要**: Web Client IDは**必須**です。iOS/AndroidのClient IDはネイティブGoogle Sign-Inを使用する場合のみ必要です。

## 🍎 Apple認証の設定（iOS）

Apple Sign-Inは**iOSのみ**で利用可能です。

### 1. Apple Developer Accountの設定

1. [Apple Developer](https://developer.apple.com/) にログイン
2. 「Certificates, Identifiers & Profiles」を選択
3. 「Identifiers」→「App IDs」を選択
4. 該当するApp IDを選択（またはCreate App IDで作成）
5. 「Sign In with Apple」にチェックを入れる
6. 「Save」をクリック

### 2. Firebase Consoleでの設定

1. Firebase Console → Authentication → Sign-in method
2. 「Apple」を有効化
   - 「Enable」をON
   - Service ID（オプション）: 空欄でOK（iOS専用の場合）
3. 「保存」をクリック

### 3. app.jsonの設定

`app.json` に以下を追加：

```json
{
  "expo": {
    "ios": {
      "bundleIdentifier": "com.yourcompany.tierhub",
      "usesAppleSignIn": true
    }
  }
}
```

### 4. Expo Configでの有効化

Expo開発ビルド（development build）またはEASビルドを使用する必要があります。Expo Goでは**Apple Sign-Inは動作しません**。

## 🔧 開発環境での確認

### Web（開発サーバー）

```bash
npm start -- --web
```

Web版ではGoogle認証のみ動作します。

### iOS Simulator

```bash
npm run ios
```

または

```bash
eas build --profile development --platform ios
```

**注意**: Apple Sign-InはExpo Goでは動作しないため、development buildまたはEAS buildが必要です。

### Android Emulator

```bash
npm run android
```

Google認証が動作します（Client IDが正しく設定されている場合）。

## ✅ テスト手順

### 1. 開発サーバー起動

```bash
npm start
```

### 2. 認証フローのテスト

1. アプリを起動
2. ログイン画面が表示される
3. 「Sign in with Google」をタップ
4. Googleアカウント選択画面が表示される
5. アカウントを選択してログイン
6. ログイン成功後、メイン画面（タブナビゲーション）に遷移

### 3. Firestore確認

Firebase Console → Firestore Database で、`users` コレクションに新しいユーザードキュメントが作成されていることを確認。

## 🐛 トラブルシューティング

### Google Sign-In が動作しない

1. `.env` ファイルのClient IDが正しいか確認
2. Firebase ConsoleでGoogle認証が有効化されているか確認
3. 開発サーバーを再起動（環境変数の変更後は必須）
4. エラーメッセージを確認：
   ```bash
   npx expo start --clear
   ```

### Apple Sign-In が動作しない

1. iOSデバイス/Simulatorで実行しているか確認（Androidでは動作しない）
2. Expo Goではなく、development build/EAS buildを使用しているか確認
3. Apple Developer AccountでSign In with Appleが有効か確認
4. `app.json` の `usesAppleSignIn` が `true` になっているか確認

### "Firebase: Error (auth/invalid-credential)"

- Web Client IDが間違っている
- Firebase側でGoogle認証が有効化されていない

### "expo-auth-session" エラー

パッケージが正しくインストールされているか確認：

```bash
npx expo install expo-auth-session expo-crypto
```
