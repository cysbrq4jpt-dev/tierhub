# 要件定義書：TierHub（格闘・FPS特化型）

> **ドキュメント種別**: UI・機能特化型 要件定義書（最終版）
> **対象プロダクト**: TierHub — 格闘ゲーム・FPS特化型 Tier表SNSプラットフォーム
> **概要**: 攻略サイト×SNS、パッチ追従、配信者向けUI、相性表の統合を反映した最終要件

---

## 1. ユーザーインターフェース（UI）要件

### 1.1 「スマート・キャンバス」エディタ（Tier表作成）

#### オート・スナップ & リフロー

アイテムを行（Tier）にドロップすると、マグネットのように整列する。アイテム数に応じてアイコンサイズが自動調整され、常に「1枚の美しい画像」として完結する。

- ドラッグ中のアイテムには吸着ガイドライン（点線）を表示
- Tier行のアイテム数が閾値を超えた場合、アイコンサイズを段階的に縮小
- レスポンシブレイアウト：端末サイズに応じた最適な列数の自動算出

#### デルタ・ゴースト表示

新バージョン作成時、前バージョンの配置を半透明で背景に表示。変更箇所の視覚化をサポートする。

- ゴースト表示のON/OFFトグル
- 変更があったアイテムにはハイライト枠を付与
- 移動方向を示す矢印アニメーション（例：B→S に移動した場合、上向き矢印）

#### パッチノート・サイドバー

作成画面の右側に、当該バージョンの修正内容をリアルタイム表示。情報を探す手間を排除する。

- 対象ゲームの公式パッチノートを自動取得・パース
- キャラ名のハイライト表示（該当キャラをキャンバス上でも強調）
- サイドバーの折りたたみ対応（モバイルではボトムシート化）

### 1.2 「ダイナミック・マトリックス」（相性表作成）

#### 直感スライダー

総当たり表の各セルをタップし、スライダーを左右に動かすだけで「6:4」「7:3」といった数値を爆速入力。数値に応じてセルの色が青（有利）〜赤（不利）へ動的に変化する。

- 入力単位：0.5刻み（例：6.5:3.5 も入力可）
- 対称セルの自動反転（A vs B を入力すると、B vs A が自動で逆値に設定）
- ロングタップで詳細メモ入力モードへ遷移

#### フォーカス・ビュー

特定キャラを選択すると、そのキャラを起点とした「全方位相性図（レーダーチャート）」へ瞬時に切り替える。

- レーダーチャートの軸は相手キャラ名で表示
- 有利・不利の閾値でゾーン分け（グリーン/イエロー/レッドゾーン）
- タップでマトリックスビューに即座に復帰

### 1.3 ストリーマー・モード（配信特化）

#### クロマキー・背景透過

背景をグリーンバック等の透過色へ1ボタン切り替え。

- 透過色の選択肢：グリーン / ブルー / マゼンタ / 完全透過（PNG出力時）
- UI要素の背景も連動して透過対応

#### UI最小化（フォーカス）

操作パネルを隠し、Tier表そのものだけを画面いっぱいに表示する。

- ショートカットキー対応（`F`キーでトグル）
- マウスホバー時のみ操作UIを一時表示

#### リアルタイム・ウィジェット

配信画面上に「現在のリスナー投票結果」をリアルタイムでオーバーレイ表示する。

- WebSocket ベースのリアルタイム同期
- 投票URL の QRコード自動生成
- 投票結果のアニメーション付き更新（バーチャート / パイチャート切り替え）

## 2. 機能要件

### 2.1 バージョン・ライフサイクル管理

#### タイムトラベル・アーカイブ

全てのTier表をパッチ（Ver.）ごとに紐づけて保存。ユーザーは「あの時の評価」へいつでも遡れる。

- パッチバージョンのタイムラインUI（横スクロール）
- バージョン間の差分表示（Diff View）
- 特定バージョンのURLパーマリンク生成

#### バフ/ナーフ・オートマーカー

公式パッチで性能変化があったキャラに、自動で「↑/↓」バッジを付与する。

- バッジ種別：↑（バフ）/ ↓（ナーフ）/ ⟳（リワーク）/ NEW（新キャラ）
- パッチノートのパース結果と連動
- マーカーのタップで変更内容のサマリーをポップオーバー表示

### 2.2 攻略データ集計（集合知）

#### ヒートマップ・オーバーレイ

自分のTier表の上に、全ユーザーの平均評価を「熱量（色）」で重ね合わせる。世論とのズレを数値化する。

- オーバーレイ表示のON/OFFトグル
- ズレ度の数値表示（例：「あなたの評価は世間と15%ズレています」）
- ズレが大きいキャラのハイライト表示

#### ランク帯別フィルタリング

「プロ・上級者・一般層」のデータを切り替えて集計・表示する。

- フィルタ条件：ランク帯 / フォロワー数 / 実績バッジ
- フィルタ適用後の母数（サンプル数）を常時表示
- 複数フィルタの組み合わせ対応

### 2.3 SNS・拡散最適化

#### インサイト付与型OGP

X（Twitter）シェア時、単なる画像だけでなく「このパッチで評価が一番上がったのは〇〇！」といったキャッチコピーを自動生成して画像に合成する。

- OGP画像の自動生成（Canvas API / サーバーサイドレンダリング）
- キャッチコピーのテンプレートパターン（5種以上）
- ゲームタイトル・パッチ番号の自動挿入

#### インタラクティブ埋め込み

外部の攻略サイトやブログに、マウスホバーで「解説メモ」が読める動的なTier表を埋め込む機能。

- `<iframe>` / `<script>` タグによる埋め込みコード生成
- レスポンシブ対応（埋め込み先のコンテナ幅に追従）
- 埋め込み表示時のブランディング（TierHubロゴ + リンクバック）

## 3. 機能・UIマトリックス（開発優先度）

| カテゴリ | 機能名 | 詳細 | 優先度 |
|---------|--------|------|--------|
| 操作 | 爆速スナップ | アイテムの自動吸着・整列 | ★★★ |
| 操作 | 相性スライダー | 0.5単位での直感的な有利・不利入力 | ★★★ |
| 表示 | パッチ・デルタ | 前Ver.からの変動アイコン自動表示 | ★★★ |
| 表示 | 配信者用背景透過 | OBS等でのレイアウト最適化 | ★★★ |
| データ | 集合知集計 | 全ユーザーの平均配置データの算出 | ★★☆ |
| データ | 解説メモ | キャラごとの配置理由をテキスト保存 | ★★☆ |

### 優先度の定義

- **★★★（Must）**: MVP（最小実行可能製品）に含める。リリース時に必須。
- **★★☆（Should）**: MVPリリース後、早期アップデートで実装。
- **★☆☆（Nice to Have）**: ユーザーフィードバックに応じて検討。

## 4. 成功の定義（上層部向けKPI）

| KPI | 指標 | 目標値 |
|-----|------|--------|
| UGCシェア数 | X（Twitter）での「#TierHub」を含む画像投稿数 | 月間 10,000 件 |
| パッチ追従速度 | 公式アップデートからテンプレート公開までの時間 | 1時間以内 |
| ドメイン権威 | 「ゲーム名 + Tier」での検索結果クリック率 | 既存攻略サイトを上回る CTR |

### 補足：KPI計測手法

- **UGCシェア数**: X API v2 のストリーミング検索でリアルタイム集計
- **パッチ追従速度**: ゲーム公式RSSフィード検知 → テンプレート公開までの経過時間を自動記録
- **ドメイン権威**: Google Search Console のクリック率レポートで月次計測

## 6. 開発フェーズ計画

### Phase 1: MVP（最小実行可能製品）

- スマート・キャンバス（オート・スナップ & リフロー）
- ダイナミック・マトリックス（直感スライダー）
- パッチ・デルタ表示（バフ/ナーフ・オートマーカー）
- ストリーマー・モード（背景透過 + UI最小化）
- 基本SNS機能（いいね、コメント、フォロー）

### Phase 2: コミュニティ・集合知

- ヒートマップ・オーバーレイ
- ランク帯別フィルタリング
- 解説メモ機能
- リアルタイム・ウィジェット（配信投票）

### Phase 3: 拡散・エコシステム

- インサイト付与型OGP
- インタラクティブ埋め込み
- タイムトラベル・アーカイブ（全バージョン履歴）
- 外部攻略サイト連携API
